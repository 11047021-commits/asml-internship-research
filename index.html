Part A研究背景

職稱和背景欄，看不出這份實習適不適合我

我目前就讀成大國際企業所，目標是進入半導體產業。準備應徵 ASML 實習時，我發現職缺名稱和官網的背景欄位很難判斷哪些職位真正適合非理工背景，有些職稱寫 Engineer，內容卻是行政與資料工作。於是我決定把 ASML 台灣的實習職缺整理成資料，自己找出答案，也藉此練習資料分析。

Problem

官網只能用職類和教育背景篩選，看不出實際工作內容；職稱也常與內容不符。

Question

ASML 台灣的實習有多少是非工程職？它們共同要求哪些工具與能力？

Goal

建立一套依工作內容分類的規則，找出我該優先補強的能力。

Part B研究過程

從 28 筆職缺建立分類規則

分類規則不是一開始就定好的。我先用簡單的工程／非工程二分法，在分類過程中遇到判斷不了的職缺，再回頭修正規則。

  1. 蒐集職缺官網篩選「Taiwan + Internship」取得開放中的 20 筆，另補 8 筆已關閉職缺
  2. 記錄原文Job ID、廠區、官網背景欄、工作內容與技能要求
  3. 依內容分類不看職稱與背景欄，只看實際要做的事
  4. 標記技能用固定詞彙表標記工具與能力，方便統計
  5. 統計與比對分類比例、廠區分布、技能頻率、落差案例
Data source

開放中的 20 筆來自官網「Taiwan + Internship」篩選；另外 8 筆已關閉職缺，官網頁面已下架，內容改取自搜尋引擎保存的官網頁面，並逐筆打開官網確認狀態。

原本的第三類是「混合」。分類時有多筆職缺被我判斷為「偏資管」，卻分別被歸進工程或混合，標準不一致，因此把「混合」改為「資管／數位」並重新定義。

研究結論

  1. 我原本以為 ASML 的實習以工程背景為主，但整理 28 筆台灣實習職缺後發現，六成是非工程職。這些職位以行政、後勤協調和文件整理為主，但其中多數也要求資料整理或分析能力。

  2. 台南的實習職缺沒有一筆需要程式或資管背景，但約一半仍要求資料分析，使用的工具以 Excel、Power BI、SAP 為主。對目前在台南讀碩士、想找實習的我來說，該優先補的是用這些工具整理和呈現資料的能力，而不是程式語言。

  3. 對照我的目標，最直接的缺口是 Power BI：它同時出現在非工程與資管類職缺，台南也有。Python 只出現在資管類職缺，是進一步擴大選擇的能力。接下來我會先用 Excel 和 Power BI 完成一份資料分析作品，並透過資料分析社補強 Python。
